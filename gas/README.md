# 折本メモ 自動復元（Google Apps Script 版）

ScanSnap で取り込んだ**折本メモのシート**を Google ドライブに入れておくと、
定期的に見張って、**元のページ順に戻した PDF** を作ります。
パソコンを開いていなくても、ドライブ側で勝手に処理されます。

```
ScanSnap ──▶ Google ドライブ（入力フォルダ）
                    │  10 分おきに GAS が見に行く
                    ▼
             1〜8 ページに戻した PDF（出力フォルダ）
             元の画像は「処理済み」フォルダへ
```

**トンボや罫線は要りません。** 白紙の A4 を折って手書きしたメモで動きます。
ScanSnap は紙の端を機械的に見つけて用紙ちょうどに切ってくれるので、
その紙をレイアウトどおりの格子に割るだけで復元できます。

---

## 準備するもの

| | |
|---|---|
| ScanSnap の保存形式 | **JPEG**（下記の理由で PDF は不可） |
| 折り方 | 面付けが `orihon8`（キンコーズ図6 と同じ 8 ページ折本）であること |
| Google アカウント | 無料のもので構いません |

> **なぜ JPEG なのか**
> Apps Script には PDF を画像に開き直す手段がありません。
> ScanSnap Home のプロファイル設定で、保存形式を JPEG にしてください。
> （PDF が入っていた場合は、飛ばして実行ログに理由を残します）

---

## 手順

### 1. ドライブにフォルダを作る

3 つ作っておくと分かりやすいです。2 つ目以降は省略できます。

- `折本メモ_入力` … ScanSnap の保存先
- `折本メモ_出力` … 復元した PDF の置き場
- `折本メモ_処理済み` … 処理し終わった元画像の置き場

フォルダを開いたときの URL の末尾が **フォルダ ID** です。

```
https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz
                                        └──────── これ ────────┘
```

### 2. Apps Script のプロジェクトを作る

1. [script.google.com](https://script.google.com/) で「新しいプロジェクト」
2. このフォルダの **`.gs` ファイルを 4 つとも**貼り付けます
   （`Config.gs` / `Layouts.gs` / `Unimpose.gs` / `Main.gs`）
   - 左の「ファイル」＋ボタンから「スクリプト」を追加し、同じ名前を付けます
3. 左の「**サービス**」＋ボタンから **Google Slides API** を追加します
   （画像の切り抜きとページの大きさの指定に使います）

### 3. 設定する

`Config.gs` の先頭を、自分のフォルダ ID に書き換えます。

```javascript
const CONFIG = {
  INBOX_FOLDER_ID:  '1AbCdEf...',   // 折本メモ_入力
  OUTPUT_FOLDER_ID: '1GhIjKl...',   // 折本メモ_出力
  DONE_FOLDER_ID:   '1MnOpQr...',   // 折本メモ_処理済み
  LAYOUT: 'orihon8',
  PAPER: 'A4',
  ...
};
```

### 4. 動かしてみる

エディタ上部の関数を選んで「実行」します。初回は権限の確認が出ます。

1. **`checkSetup`** … 設定と権限の点検。`[NG]` があれば直します
2. 入力フォルダにシートの画像を 1 枚入れて、**`runOnce`** … 1 件だけ試します
   - 出力フォルダに `〇〇_元原稿.pdf` ができ、1〜8 ページに戻っていれば成功です
   - 元ファイルは動かさないので、何度でも試せます
3. **`installTrigger`** … 10 分おきの定期実行を登録します

これで、ScanSnap から入力フォルダに入れるだけで勝手に処理されます。

止めたくなったら **`removeTrigger`** を実行してください。

## うまくいかないとき

| 症状 | 直し方 |
|---|---|
| ページが上下逆 | `CONFIG.SHEET_ROTATE` を `180` に |
| ページが横倒し | `CONFIG.SHEET_ROTATE` を `90` か `270` に |
| ページの順番がばらばら | 折り方が違うかもしれません。`CONFIG.LAYOUT` を変えてみてください（`orihon8-right` など） |
| 全ページ寝ている | `CONFIG.PAGE_ROTATE` を `90` か `270` に |
| 端が切れる／ずれる | ScanSnap 側で「原稿の傾き・向きを自動補正」を有効にしてください |
| PDF が飛ばされる | ScanSnap の保存形式を JPEG にしてください |
| `Slides is not defined` | 「サービス」から Google Slides API を追加してください |

**切り分けを目で確かめたいとき**は、パソコン版（Python）の方が便利です。

```
orihon unimpose スキャン.jpg --preview
```

赤い枠と番号がシートに重なった PDF ができるので、
どこをどのページとして切り出すつもりか一目で分かります。

## しくみ

Apps Script には PDF を切り貼りする手段がないので、
**Google スライドをレンダラとして使っています**。

1. 復元後 1 ページと同じ大きさ（A4 → A7）のプレゼンテーションを作る
2. 1 スライドにつき、シートの画像を 1 枚敷く
3. Slides API の切り抜き（`cropProperties`）で、そのページのマスだけを残す
4. 面付けでかかっていた回転を打ち消す（上段は 180 度戻す）
5. できたプレゼンテーションを PDF に書き出し、作業用ファイルは捨てる

どのマスが何ページ目かという表は `Layouts.gs` にありますが、
**これは自動生成です**。おおもとは Python 版の `src/orihon/layouts.py` で、

```
python tools/make_gas_layouts.py
```

で作り直せます。`tests/test_gas.py` が Node で GAS のコードを実際に走らせて、
Python 版と同じ答えになることを確かめているので、両者がずれることはありません。

## パソコン版との違い

| | GAS 版 | パソコン版（`orihon unimpose`） |
|---|---|---|
| 入力 | JPEG / PNG | PDF・JPEG・PNG など |
| 紙の位置の検出 | しない（ScanSnap が切ってくれる前提） | する（フラットベッドの余白にも対応） |
| 切り分けの確認 | なし | `--preview` で図示 |
| 複数枚のシート | 1 ファイル 1 枚 | 複数ページの PDF に対応 |
| 動かす場所 | クラウド（PC 不要） | Windows / macOS / Linux |
